# Componentes UI

Este apartado debe documentar componentes visuales reutilizables que no dependen directamente de la malla curricular.

## Que debe ir aqui

- Botones, inputs, selects, tabs, modales, alertas y tarjetas genericas.
- Componentes de feedback como loaders, mensajes de error o estados vacios.
- Convenciones de estilo compartidas por toda la interfaz.
- Reglas de accesibilidad y tamanos minimos de componentes interactivos.

## Que no debe ir aqui

- Componentes especificos de asignaturas o prerequisitos.
- Logica de negocio o llamadas HTTP.
- Layouts completos de pagina.

## Estado actual

Todavia no hay componentes UI propios en esta carpeta. Al crearlos, documentar nombre, proposito, props principales y cuando reutilizarlos.
