# Layouts

Este apartado debe documentar estructuras de pantalla reutilizables.

## Que debe ir aqui

- Layout principal de la aplicacion.
- Barras de navegacion, contenedores de pagina y zonas persistentes.
- Estructuras responsive para escritorio y movil.
- Layouts autenticados o publicos si el sistema separa sesiones.

## Que no debe ir aqui

- Componentes pequenos de UI como botones o inputs.
- Reglas de negocio de malla o progreso.
- Servicios de acceso a datos.

## Estado actual

No hay layouts implementados aun. Cuando se creen, documentar que pantallas usan cada layout y que regiones visuales define.
